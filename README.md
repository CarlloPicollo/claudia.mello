# Site Claudia Mello

Site estatico (HTML, CSS e JS), sem instalacao.

## Publicar no GitHub Pages
1. Suba todo o conteudo desta pasta para um repositorio (index.html na raiz).
2. Settings > Pages > Deploy from a branch > main > / (root) > Save.
3. O endereco aparece na mesma tela em alguns minutos.

## Idiomas
Textos em portugues ficam no HTML. A versao em espanhol fica no atributo data-es de cada elemento.
O site abre em espanhol sozinho para quem tem o navegador em espanhol.
